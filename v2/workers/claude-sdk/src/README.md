# Claude SDK worker

`main.ts` hosts the pinned supported Agent SDK, streaming input, native permission/question callbacks, images, interruption, stopping one sub-agent (`stop_agent`), and managed command tools. Sub-agent prose is forwarded (`forwardSubagentText`) and coding agents get progress summaries (`agentProgressSummaries`); `status.ts` attributes a sub-agent's text and tools by `parent_tool_use_id` and adds its brief, usage, summary and outcome to `agent_status` data. `settings.ts` gives only the Help assistant the `lazybox_settings` MCP server: reading Lazybox's settings needs no approval, and an update runs only for an input the user allowed on its approval card. Go owns queueing, journals, account context, and command execution. Build with `make build-worker`; see `RUNNING.md` for limits.
