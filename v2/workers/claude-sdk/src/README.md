# Claude SDK worker

`main.ts` hosts the pinned supported Agent SDK, streaming input, native permission/question callbacks, images, interruption, stopping one sub-agent (`stop_agent`), switching the model of the following turns (`model`, the SDK's `setModel`), and managed command tools. `catalog.ts` reports the agent's own slash commands and models once per change as `command_catalog` (from the initialize response, each turn's `init`, and `commands_changed`); a command is run by sending `/name args` as the message. `status.ts` reports a compaction as `compacted` and a local command's printed output as the agent's text. Sub-agent prose is forwarded (`forwardSubagentText`) and coding agents get progress summaries (`agentProgressSummaries`); `status.ts` attributes a sub-agent's text and tools by `parent_tool_use_id` and adds its brief, usage, summary and outcome to `agent_status` data. `settings.ts` gives only the Help assistant the `lazybox_settings` MCP server: reading Lazybox's settings needs no approval, and an update runs only for an input the user allowed on its approval card. Go owns queueing, journals, account context, and command execution. Build with `make build-worker`; see `RUNNING.md` for limits.
