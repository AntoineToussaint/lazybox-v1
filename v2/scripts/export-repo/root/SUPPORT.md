# Support

Lazybox V2 is pre-release and developed in a private repository.

## Questions, bugs and feature requests

Open an [issue](https://github.com/AntoineToussaint/lazybox/issues/new) in this
repository, or email
[toussaint.antoine@gmail.com](mailto:toussaint.antoine@gmail.com).

For a bug, include:

- The commit you ran (`git rev-parse HEAD`), or the Working release ID
  (`make environments`).
- Your macOS version and whether it happened in Dev or Working.
- The launcher's terminal output around the failure, and a screenshot for
  anything visual.

For a feature request, lead with the problem you are hitting, not just the
feature you have in mind.

## Documentation

Start at [`README.md`](README.md); it indexes the design and operating
documents. Contributor process is in [`CONTRIBUTING.md`](CONTRIBUTING.md).

Potential vulnerabilities should not be posted as issues. Follow
[`SECURITY.md`](SECURITY.md).
